# v1.1 · UI 优化与一键查找版

本工具基于 [Turing-Mirror/PCL-Helper](https://github.com/Turing-Mirror/PCL-Helper) 修改，保留原作者 Turing Mirror Software / 图灵镜的版权声明和 MIT 许可证。原补丁核心未修改，详见根目录 NOTICE.md。

- 优化原生 WPF 界面、图标、状态反馈和小屏窗口布局。
- 增加一键查找 PCL、后台进度、取消搜索和多结果选择。
- 找到唯一兼容结果时自动填入并检查；修复仍由用户手动确认操作。
- 仅支持修复 PCL 2.99.0.0。
- 14 项搜索检查、41 项 WPF 集成检查、原补丁与 SHA256 还原检查通过。

运行环境：Windows 10/11，系统 .NET Framework 4.5 或更新版本，建议 4.8。

验证边界：已做真实文件副本的补丁和还原、WPF 集成检查及离线渲染；未验证完整 Minecraft 下载和所有整合包格式的端到端安装。详情见 docs/UI-VALIDATION.md。

成品 EXE、便携 ZIP、离线源码包和 SHA256 校验值位于 dist/v1.1/。
