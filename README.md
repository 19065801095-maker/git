## PCL-Helper · UI 优化与一键查找版

**本工具基于 [Turing-Mirror/PCL-Helper](https://github.com/Turing-Mirror/PCL-Helper) 修改。** 原作者为 Turing Mirror Software / 图灵镜，保留原作者署名和 MIT 许可证。

本修改版优化原生 WPF 界面，增加一键查找 PCL、后台搜索、取消和多结果选择；原补丁引擎保持原样。它不是上游官方发布版，也不是 PCL 官方工具。详细声明见 [NOTICE.md](PCL-Helper/NOTICE.md)。
